# Security policy

## Reporting a vulnerability

Report vulnerabilities through GitHub private vulnerability reporting:
open [Report a vulnerability](https://github.com/ibukimatsubara/dequ-local/security/advisories/new) on the repository's **Security** tab.

Do not report vulnerabilities in public issues, pull requests or discussions, because anyone can read them before a fix is released.

Please include:

- the affected version or commit,
- what an attacker can do, and under which conditions,
- steps or a proof of concept to reproduce it.

The maintainer replies in the private report, and publishes an advisory after a fix is released.

## Supported versions

Security fixes are made on the latest release only.
