# DeQu brand assets

The DeQu mark is a decision diamond split in two: one half chosen (filled), the other left open (outlined).

| File | Use |
| --- | --- |
| `dequ-mark.svg` | Master symbol, black, 256×256 |
| `dequ-mark-small.svg` | Simplified drawing for 16–48 px (thicker outline) |
| `export/dequ-white.svg`, `export/dequ-black.svg` | One-colour versions for dark and light backgrounds |
| `export/dequ-app-icon.svg` | White mark on a `#111111` rounded square |
| `export/favicon.svg` | Browser tab icon; switches to white in dark mode |
| `export/favicon.ico`, `export/favicon-*.png` | Favicon fallbacks drawn from the small version |
| `export/apple-touch-icon.png`, `export/icon-*.png`, `export/maskable-512.png`, `export/site.webmanifest` | Home-screen and PWA icons |

The mark is black or white only. Do not recolor, rotate or stretch it.
